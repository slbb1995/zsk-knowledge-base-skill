# 时长伸缩参考

> 使用说明：实验性方法论参考；用于时长适配，不直接作为口播主线候选。

时长适配不是按字数机械裁剪，而是决定一条内容能容纳多少层信息，以及开头到第一次价值兑现之间可以有多少过渡。下面是写作参考，不是固定标准。

| 时长 | 结构容量 | 保留方式 |
|---|---|---|
| 15—30 秒 | 一个承诺、一个价值点、一个动作 | 合并对象与开场；证据只留最强一条 |
| 30—60 秒 | 一条完整基础结构 | 允许一层原因、比较或 1—3 步 |
| 60—90 秒 | 完整结构加一层解释 | 可以增加转折、例子或阶段提示 |
| 90—180 秒 | 分段展开 | 2—3 个小节，每节都回扣总承诺 |
| 180—300 秒 | 多段完整论证 | 适合使用显式路标、阶段小结和节奏变化 |

## 压缩顺序

1. 删除重复解释和修饰。
2. 删除次要例子。
3. 合并对象锚定与开场承诺。
4. 把多个证据缩为最强证据。
5. 优先保留核心问题和兑现路径，再判断证据、边界和结尾需要保留多少。

涉及事实、产品或高风险判断时，压缩不等于省略会改变结论的前置条件和限制。

## 展开顺序

1. 增加必要背景，不增加新主题。
2. 增加一层原因或步骤。
3. 增加可核验证据。
4. 增加分段提示和注意力重置。
5. 结尾可以回收开场，也可以自然停在最有价值的判断上。

## 语速

字数适合初稿估算，真正时长更适合通过朗读感受。复杂术语、数字、停顿和镜头动作都会影响语速，同一字数不一定对应同一时长。
