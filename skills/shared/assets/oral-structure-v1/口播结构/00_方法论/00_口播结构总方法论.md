# 口播结构总方法论

> 使用说明：稳定方法论参考；用于理解结构和选择主线，不直接作为口播主线候选。

## 定位

这是一套“把真实材料组织成可说出口内容”的方法，不是保证播放量的爆款公式。

结构库解决正文如何推进；传播结果还同时受到选题需求、标题封面、首帧、声音画面、账号基础、发布时间和分发方式影响。

## 一种常用的组织思路

```text
内容目标
→ 受众当前状态
→ 已有真实素材
→ 选择一条主要推进线
→ 需要时组合其他结构或增强机制
→ 用功能锚点检查有没有讲清楚
→ 按时长压缩或展开
→ 生成口播
```

这不是固定流程。也可以先写出一个自然版本，再反过来判断它主要用了什么结构、哪里需要补强。

## 三个使用原则

1. **结构是工具，不是答案。** 可以用一个结构，也可以确定一条主线后组合其他结构片段。
2. **AI 可以创造“怎么讲”。** 钩子、顺序、类比、节奏和表达都可以变化。
3. **结构不替代事实。** 经历、客户、数字、对话和结果没有材料时，可以保留变量槽位、改写成一般性表达，或先完成结构草图。

## 选择结构的三个问题

1. 看完后，观众应该理解、相信、学会、选择还是行动？
2. 观众现在缺的是原因、步骤、判断标准、证据还是场景体验？
3. 当前材料足以兑现什么强度的承诺？

[[02_结构选择矩阵]]可以帮助快速找方向；[[01_七个功能锚点]]适合在写完后检查，不要求每条内容逐项集齐。

## 结构与素材怎样分工

- 结构库提供讲述顺序、理解路径和表达选择。
- 个人经历、客户故事、产品信息和数据由实际素材提供；缺少时先用中性变量槽位表示。
- 案例可以帮助理解方法，但不是每张结构卡都需要配例子。
- 画面、剪辑和声音可以增强结构，也可以在后续制作阶段单独设计。
