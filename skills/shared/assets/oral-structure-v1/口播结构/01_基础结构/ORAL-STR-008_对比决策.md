# 对比决策

> 使用说明：基础结构，可作为口播主线候选；来自多来源模式归纳。

## 用途

把多个方案放在同一判断轴上比较，最后给出随条件变化的选择建议。

## 适合的内容

- 方案面向同一任务。
- 有统一、真实的比较维度。
- 每个方案都有优势、限制和适用条件。

如果创作者已经预设唯一答案，这个结构仍然可以帮助检查：比较轴是否公平，是否遗漏了另一方案真正重要的条件。

## 功能顺序

```text
真实决策场景
→ 共同目标
→ 判断维度
→ 方案 A
→ 方案 B
→ 关键差异
→ 条件化建议
```

## 可以重点关注

- 决策场景承担开场和对象感。
- 同一判断轴承担兑现路径。
- 可核验参数、规则或实测承担证据。
- “如果……选 A；如果……选 B”承担结尾动作。

## 时长

- 30 秒内：一个关键维度和条件化结论。
- 30—90 秒：二到三个维度、优势和限制。

## 素材不足时怎么用

可以先列出共同目标、比较维度和待确认条件，再决定是否展开结论。这个结构提供选择视角，不替观众做掉那些只能由个人情况决定的判断。

## 容易写坏的地方

- 比较对象不在同一层级。
- 用单一参数给绝对结论。
- 故意隐去自己偏好方案的缺点。

## 与切入角度结合

成本、标杆、反差、人群和怀旧都可以帮助确定比较对象。比较仍须围绕同一任务和可比条件，说明不同方案的得失。人群角度要落实到真正影响选择的条件，历史比较要解释年代环境。结尾给条件化建议；若资料不足，只说明哪些比较还不能成立。

## 材料不足与方向边界

占位、换结构或换主题仅用于批准前的内部设计。正式正文不留占位符，不虚构经历、案例和数据；获批后若缺口使核心承诺无法兑现，交回入口保留当前任务并说明恢复路径，不由 Writer 静默换题。
