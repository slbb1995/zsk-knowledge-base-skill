# 一个结论多个证据

> 使用说明：基础结构，可作为口播主线候选；当前属于实验性参考，使用后应记录反馈。

## 用途

先给出本期最重要的结论，再用两到三个同主题事实支撑，并把每条事实翻译为“这对目标观众意味着什么”。

## 适合的内容

- 多条事实围绕同一个结论。
- 每条事实都有原始来源和日期。
- 能区分事实、解释和预测。

它既可以用于数据内容，也可以用于周报、行业观察、观点论证和信息汇总。

## 功能顺序

```text
本期结论
→ 证据一与含义
→ 证据二与含义
→ 可选证据三与含义
→ 不确定性
→ 分人群行动建议
```

## 可以重点关注

- 结论承担开场承诺。
- 每个“证据＋这意味着”构成一次兑现和注意力重置。
- 结尾可以根据不同人群给出不同判断，也可以停在一个清晰结论上。

## 时长

- 30—60 秒：一个结论、两个证据。
- 60—120 秒：三组证据和不确定性。
- 120—300 秒：显式分段、来源提示、阶段小结。

## 素材不足时怎么用

可以先搭出“结论＋证据位置＋这意味着什么”的框架。来源或日期还没补齐时，把对应位置留空；信息仍在变化时，用“当前观察”比确定性预测更合适。

## 容易写坏的地方

- 把月报写成读数单。
- 先堆信息，最后才给结论。
- 用三个不同主题凑“三个证据”。
- 把作者自报当平台核验数据。

## 与切入角度结合

标杆、反差或历史变化可以提出值得解释的问题。先判断现有证据能支持多强的结论，再组织每条事实及其含义。不能先定一个极端标题，再用不相干材料凑证据。结尾明确结论范围及对读者的意义。本页为实验性参考，采用需明确实验授权，不表示已验证效果。

## 材料不足与方向边界

占位、换结构或换主题仅用于批准前的内部设计。正式正文不留占位符，不虚构经历、案例和数据；获批后若缺口使核心承诺无法兑现，交回入口保留当前任务并说明恢复路径，不由 Writer 静默换题。
