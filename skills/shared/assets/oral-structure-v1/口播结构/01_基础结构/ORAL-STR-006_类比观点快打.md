# 类比观点快打

> 使用说明：基础结构，可作为口播主线候选；来自多来源模式归纳。

## 用途

用一个熟悉、可视化的关系解释抽象观点，让观众快速理解并记住判断。

## 适合的内容

- 类比两端存在可说明的对应关系。
- 观点可以在一句话中准确复述。
- 能明确类比在哪些地方失效。

类比可以来自日常画面、工作过程或熟悉关系，不需要绑定某个固定案例。

## 功能顺序

```text
熟悉画面或问题
→ 映射到抽象主题
→ 核心观点
→ 一到两个理由
→ 类比边界
→ 可带走的判断
```

## 可以重点关注

- 类比画面承担开场承诺和注意力重置。
- 映射关系承担兑现。
- 理由或外部事实承担证据，类比本身不是事实证据。

## 时长

- 15—30 秒：一个画面、一个映射、一个观点。
- 30—60 秒：增加理由和边界。

## 容易写坏的地方

- 只说“就像”，没有解释对应关系。
- 类比比主题更难理解。
- 用类比替代证据。
- 为了金句删除适用条件。

## 与切入角度结合

怀旧物件、成本关系或陌生现象都可提供类比入口，但应选择读者容易理解的关系，并说清与主题对应的部分。类比帮助解释判断，不证明业务结果。结尾回到真实主题，留下可用判断，不停在一个漂亮比喻上。

## 材料不足与方向边界

占位、换结构或换主题仅用于批准前的内部设计。正式正文不留占位符，不虚构经历、案例和数据；获批后若缺口使核心承诺无法兑现，交回入口保留当前任务并说明恢复路径，不由 Writer 静默换题。
