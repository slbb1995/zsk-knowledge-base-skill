# 诊断纠偏

> 使用说明：基础结构，可作为口播主线候选；来自多来源模式归纳。

## 用途

围绕一个明显症状，定位最优先核对的原因，并给出修正顺序。

## 适合的内容

- 观众已有具体症状。
- 能区分现象、推断和已核验原因。
- 能给出优先级，而不是罗列十个可能。

面对复杂医疗、法律、财务或保险问题，这个结构更适合帮助观众建立核对顺序，而不是替观众直接下结论。

## 功能顺序

```text
具体症状
→ 常见误判
→ 优先核对的主因
→ 判断依据
→ 修正顺序
→ 不适用情况
```

## 可以重点关注

- 开场承诺：告诉观众先检查哪里。
- 单一核心问题：只诊断一个症状。
- 证据：事实、可重复检查或明确逻辑。
- 注意力重置：从症状切到主因，再切到第一个动作。

## 时长

- 15—30 秒：一个症状、一个主因、一个检查动作。
- 30—90 秒：增加误判、依据和修正顺序。

## 素材不足时怎么用

可以先写 `【症状】→【常见误判】→【优先核对项】→【第一个动作】`。无法排除多因素时，用“先核对……”或“更值得先看……”通常比“真正原因就是……”更准确。

## 容易写坏的地方

- 把抱怨写成诊断。
- 用玄学归因制造权威。
- 省略判断依据，只给强结论。
