# 产品教程与轻转化

> 使用说明：基础结构，可作为口播主线候选；属于平台使用建议，不代表效果保证。

## 用途

先让观众看懂产品、服务或课程如何解决一个具体问题，再给出低压力的下一步。

## 适合的内容

- 场景和问题具体。
- 有真实可演示过程。
- 结果、限制和适用人群能够如实说明。

保险、医疗、金融、法律和收益类主题通常更需要把功能、适用条件和结果边界分开讲清楚。

## 功能顺序

```text
使用场景
→ 当前问题
→ 产品或服务如何介入
→ 一段真实演示
→ 可核验结果与限制
→ 适用人群
→ 低压力行动
```

## 可以重点关注

- 场景承担对象感。
- 演示承担兑现和证据。
- 操作变化、画面切换或结果检查承担注意力重置。
- CTA 可以根据观众当前意愿选择，也可以用一个判断或使用建议自然结束。

## 时长

- 20—45 秒：场景、一个功能、一个结果检查。
- 45—120 秒：增加演示、限制和常见问题。

## 素材不足时怎么用

如果只有功能资料，可以先解释“它是什么、在什么场景下怎么用”，把价格、入口、效果和限制留成待补项。无法确认结果时，描述功能和使用条件比承诺效果更稳妥。

## 容易写坏的地方

- 一开头讲品牌历史。
- 罗列功能，不对应使用场景。
- 把整场营销活动结果归因给一条脚本。
- 在价值尚未交付时强推私信或成交。
