# 痛点镜像与反常识解法

> 使用说明：基础结构，可作为口播主线候选；来自多来源模式归纳。

## 用途

让观众先认出自己的具体落差，再发现旧解释不完整，并获得一条新的理解或行动路径。

## 适合的内容

- 受众已经感到问题，但仍在重复一个效果有限的做法。
- 有证据说明旧解释为什么不完整。
- 新解法能落实成可验证动作。

如果暂时只有一句“反常识”口号，可以先把新解释和实际动作补出来，再决定是否使用这条结构。

## 功能顺序

```text
对象与具体痛点
→ 常见做法或旧解释
→ 反常识转折
→ 新原因或新原则
→ 一到三个修正动作
→ 适用边界与下一步
```

## 可以重点关注

- 先让观众认出具体问题，再给转折，避免一上来只喊反常识。
- 事实型反常识适合补充证据，观点型反常识适合把推理过程讲清楚。
- “问题不在……而在……”可以承担转折，也可以换成提问、对比或一个新观察。

## 时长

- 15—30 秒：痛点、一个转折、一个动作。
- 30—60 秒：增加旧做法为什么无效。
- 60—90 秒：增加证据和适用边界。

## 素材不足时怎么用

可以先保留 `【具体痛点】→【旧解释】→【新解释】→【修正动作】` 的结构草图。证据不足时可写成“基于目前观察，更可能是……”，不要把一个假设包装成行业共识。

## 容易写坏的地方

- 为了冲突虚构一个没人相信的误区。
- 开头很强，正文只换了说法，没有兑现。
- 把单一案例写成普遍因果。
