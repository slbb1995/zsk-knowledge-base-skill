# 研究依据与成熟度说明

> 使用说明：稳定方法论参考；用于判断证据与使用边界，不直接作为口播主线候选。

这些标签帮助使用者理解方法来自哪里、成熟到什么程度，不负责限制谁能调用。实验性方法也可以用于创作，只需要把它当成待观察的选择，而不是已经证明有效的规律。

## evidence_scope

| 值 | 含义 | 能证明什么 |
|---|---|---|
| `platform_guidance` | 平台官方指南或官方案例 | 平台建议或单一活动事实 |
| `multi_source_pattern` | 多个独立来源反复出现 | 结构具有归纳价值 |
| `theory_transfer` | 学术或相邻场景机制迁移 | 可以提出候选假设 |
| `real_publish_data` | 本库真实发布和后台数据 | 指定账号、平台、样本范围内的观察结果 |

## maturity 怎样理解

- `stable_reference`：方法描述相对完整，适合直接参考。
- `experimental_reference`：方法仍处于实验或补证阶段，可以试用并观察实际表现。
- `historical_reference`：历史上使用过，但已有更清楚的替代方案或发现明显问题。

## 怎样积累可信度

一个结构是否真的适合某类内容，通常可以从这些角度逐步积累判断：

1. 是否有真实使用样本。
2. 样本来自什么账号、平台和主题。
3. 不同版本主要改变了什么。
4. 观众在哪些位置留下、流失、互动或转化。
5. 结构之外还有哪些变量同时发生变化。

样本少时可以记录“这次有效或无效”，不急着把它升级成普遍规律。

## 需要重新理解的情况

- 原始链接失效且没有受控证据。
- 发现案例是合成示例或作者自报被误当平台数据。
- 结构只在一个极特殊行业或账号成立。
- 方法容易诱发事实替换、虚构结果或明显误导。

本库只采用以上可复核的规则；尚无可靠依据的断言不作为写作方法使用。
