# 嵌套开放回路

> 使用说明：实验性增强机制，只能补强已选主线，不能单独作为口播主线。

## 机制

在总承诺内设置少量阶段问题，使中长内容分段推进。

```text
总问题
→ 子问题一并兑现
→ 子问题二并兑现
→ 回收总问题
```

## 使用提示

- 中长内容更容易用到，短内容也可以只保留一个总问题和一个子问题。
- 同时打开的问题越多，观众越容易忘记主线；通常保留少量问题更清楚。
- 子问题可以依次关闭，也可以在结尾统一回收，取决于内容节奏。
- 这是可实验的组织方式，不代表一定提升留存。

## 常见风险

问题越开越多、故意拖延答案、结尾忘记回收总承诺。
