# 信息缺口

> 使用说明：实验性增强机制，只能补强已选主线，不能单独作为口播主线。

## 机制

开头只制造一个与核心承诺直接相关的小缺口，并在正文尽快补上。

```text
已知信息
→ 一个关键未知
→ 明确承诺
→ 快速兑现
```

## 使用提示

- 它既可以强化已有结构，也可以直接成为一个短内容的开头。
- 缺口最好在当前内容里尽快回应。
- 比起虚假悬念或“最后告诉你”，与核心问题直接相关的小缺口更自然。
- 信息缺口理论不能证明短视频完播率必然提升。

## 可以观察什么

可以比较前段留存、第一次兑现位置和观众流失点，也可以直接观察：观众是否愿意继续听，以及答案出现时是否觉得值得。
