# 分段与信号提示

> 使用说明：实验性增强机制，只能补强已选主线，不能单独作为口播主线。

## 机制

用明确路标帮助观众知道“现在讲到哪、下一步是什么”。

可用信号：

- “先看原因，再看怎么改。”
- “第一步完成后，你应该看到……”
- “这两个数字分别说明……”
- “最后回到开头的问题。”

## 使用提示

- 60 秒以上优先考虑，短稿只保留最必要路标。
- 路标最好推进结构，而不是重复标题。
- 原始理论来自学习材料组织，迁移到口播属于 `theory_transfer`。

## 可以观察什么

可以观察分段前后的流失、重看和评论中的理解偏差，也可以通过朗读判断路标是否让表达更顺。
